# Hichem Construction — Equipment Rental Website

Responsive React + Tailwind CSS website for construction equipment rental in Blida, Algeria.

## Quick preview (no deployment or installation)
1. Extract the ZIP while keeping the folders together.
2. Open `preview.html` in Chrome, Edge, Firefox or Safari on your laptop. It also works on mobile if you open the file with a browser/file manager that supports local HTML.
3. Product cards, rental-period pricing, category filters, WhatsApp contact links and section navigation work in the preview.

## Run the React source
Requires Node.js 18+ and internet access for package installation.

```bash
npm install
npm run dev
```
Open the local URL Vite prints (usually `http://localhost:5173`).

To make a production build:

```bash
npm run build
npm run preview
```

## Customisation notes
- Equipment prices are example/indicative prices in DZD and should be confirmed before publishing.
- Update equipment entries in `src/main.jsx` to change the equipment list, image, or prices.
- Images supplied by the client are in `public/images/`.
- The WhatsApp number is configured as `+213541820051`; email and Instagram are set to the details provided.
